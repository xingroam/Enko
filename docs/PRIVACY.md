# Privacy Policy

Last updated: 2026-07-12

This Privacy Policy explains how Enko handles data when you use the software.

## 1. Scope

This policy applies to the Enko application and related project documentation in this repository.

## 2. Core Data Principle

Enko is designed for local operation on your device.

## 3. Clipboard and Input Data

Based on the current implementation goals:
- Clipboard-related content is intended to be handled locally on the device.
- Sensitive payloads are intended to be protected in memory and configuration data may be protected at rest.
- User settings may be stored locally using system-provided storage mechanisms.

You are responsible for validating the behavior of the specific version you build or run.

## 4. Permissions

Enko may request operating-system permissions (for example, Accessibility permissions on macOS) to support shortcut handling and input automation features.

These permissions are requested only to enable related features. You can manage or revoke permissions in system settings.

## 5. Network Activity

Enko is intended to function without mandatory cloud sync for clipboard operations. If any feature requires network access (for example, update checks, links opened by user action, or optional services), that activity depends on feature usage and configuration.

## 6. Sharing and Disclosure

The project does not intend to sell personal data.

Any disclosure may occur only when:
- You explicitly trigger an external action (for example, opening an external URL)
- Required by law or legal process
- Needed to protect the project, users, or public safety

## 7. Data Retention

Locally stored settings remain on your device until changed or removed by you, the application, or the operating system.

## 8. Open Source Transparency

Because this project is open source, data-handling behavior can be reviewed in source code. You should audit and validate builds before production use.

## 9. Children's Privacy

This project is not directed to children under 13, and it does not intentionally collect personal data from children.

## 10. International Use

If you use this software in a jurisdiction with specific privacy requirements, you are responsible for ensuring your own compliance.

## 11. Changes to This Policy

This policy may be updated over time. The "Last updated" date indicates the latest revision.

## 12. Contact

For project-related questions, use the repository issue tracker or maintainers' public contact channels.
